# Ανάλυση διακύμανσης — διδακτική συνέχεια

Ελληνική παρουσίαση Quarto / revealjs για προπτυχιακούς/ές προσχολικής εκπαίδευσης. Συνέχεια της διάλεξης 04 του μαθήματος «Ποσοτικές Μέθοδοι». Προτεινόμενη διάρκεια 100–110 λεπτά με πρακτική άσκηση. Το παράρτημα R είναι προαιρετικό.

## Προβολή

Ανοίξτε το `index.html` σε φυλλομετρητή. Χρησιμοποιήστε τα βέλη και πατήστε S για τις σημειώσεις διδασκαλίας. Η παρουσίαση διατηρεί την κάθετη πλοήγηση της προηγούμενης διάλεξης. Το HTML παράχθηκε με `embed-resources: true` και περιλαμβάνει τα γραφήματα, τη μορφοποίηση και το MathJax. Σε επόμενη απόδοση με διαφορετική έκδοση Quarto, ελέγξτε την προβολή των τύπων χωρίς σύνδεση.

## Επεξεργασία και απόδοση

```bash
quarto render index.qmd --to revealjs
```

Δεν απαιτείται R ή Python για την απόδοση του QMD, επειδή οι επαληθευμένοι πίνακες και τα SVG περιλαμβάνονται ήδη. Το `custom.scss` είναι ακριβές αντίγραφο του αντίστοιχου αρχείου της διάλεξης 04. Διατηρούνται διαστάσεις 1280×720, παλέτα, υποσέλιδο, πλαίσια, γραμματοσειρές και συμβολισμοί. Δεν προστέθηκε διαφορετικό λογότυπο ή όνομα συγγραφέα.

## Αρχεία

- `index.qmd`: επεξεργάσιμη παρουσίαση, με σημειώσεις ομιλητή και λύσεις.
- `index.html`: έτοιμη παρουσίαση.
- `custom.scss`: αυθεντικό θέμα της προηγούμενης διάλεξης.
- `anova_study.csv`: 90 γραμμές και ακριβώς 3 στήλες.
- `figures/`: 5 διαγράμματα SVG.
- `scripts/analyze.py`: αναδημιουργία δεδομένων, αποτελεσμάτων και διαγραμμάτων.
- `scripts/analysis.R`: πλήρης ανάλυση στην R με base / stats.
- `results.json`: αριθμητικά αποτελέσματα χωρίς στρογγυλοποίηση.

## Δεδομένα και προσομοίωση

Μία γραμμή ανά υποθετικό παιδί. `child_id`: μοναδικός κωδικός. `story_method`: Α = αφήγηση, Β = εικόνες, Γ = κούκλες. `comprehension_score`: υποθετική σύνθετη βαθμολογία κατανόησης 0–100. Το ID δεν είναι ερμηνευτική μεταβλητή.

Δημιουργήθηκαν 30 ανεξάρτητες κανονικές τιμές ανά ομάδα, με πληθυσμιακούς μέσους 50, 51, 63 και κοινή τυπική απόκλιση 10. Χρησιμοποιείται `numpy.random.default_rng(20261104)`, με στρογγυλοποίηση σε ένα δεκαδικό. Καμία τιμή δεν χρειάστηκε αποκοπή στα όρια 0–100. Το σενάριο επιλέχθηκε διδακτικά ώστε να διακρίνονται μεγάλες από μικρές διαφορές· δεν αποτελεί πραγματική έρευνα. Το αρχικό παράδειγμα των 15 παιδιών χρησιμοποιείται μόνο στην εισαγωγή των η² / ω².

```bash
python3 -m pip install numpy scipy matplotlib
python3 scripts/analyze.py
Rscript scripts/analysis.R
```

Ο Python κώδικας είναι η εκτελεσμένη αριθμητική αναφορά (NumPy / SciPy / Matplotlib). Η R ανάλυση παρέχεται ως ισοδύναμος κώδικας αναπαραγωγής. Αλλαγή του CSV ή της προσομοίωσης απαιτεί ενημέρωση και των στατικών πινάκων στο QMD· δεν ενημερώνονται αυτόματα.

## Κύρια αποτελέσματα

F(2,87) = 16,72125, p = 7,1642e-7. η² = 0,277664, ω² = 0,258909.
Tukey: Β−Α = 4,6467 (p = 0,173434), Γ−Α = 14,56 (p = 5,6776e-7), Γ−Β = 9,9133 (p = 0,000643866).
Τα 95% ΔΕ είναι ταυτόχρονα για όλα τα τρία ζεύγη. Οι δύο εκδοχές Levene (μέσος / διάμεσος) δηλώνονται ρητά, επειδή τα λογισμικά μπορεί να χρησιμοποιούν διαφορετικές προεπιλογές.

## Έλεγχοι παράδοσης

Η παρουσίαση αποδόθηκε επιτυχώς με Quarto 1.8.27. Επιβεβαιώθηκαν 54 διαφάνειες, η γλώσσα el, η παρουσία όλων των γραφημάτων και οι 90 εγγραφές / 3 στήλες του CSV. Το θέμα έχει ίδιο SHA-256 με το αρχικό. Οι αριθμοί υπολογίστηκαν με SciPy 1.17.0 και ελέγχθηκαν με ισοδύναμους τύπους. Η R δεν ήταν διαθέσιμη και ο κώδικας R δεν εκτελέστηκε. Ο πλήρης οπτικός έλεγχος του revealjs σε φυλλομετρητή δεν ολοκληρώθηκε λόγω περιορισμού εκκίνησης του browser στο περιβάλλον παραγωγής.

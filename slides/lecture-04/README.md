# One-way ANOVA — Quarto / revealjs (ελληνικά)

Εκπαιδευτική παρουσίαση για προπτυχιακούς/ές φοιτητές/τριες προσχολικής εκπαίδευσης, με ύφος και τεχνική δομή προσαρμοσμένα από το [αποθετήριο «Ποσοτικές Μέθοδοι»](https://github.com/rekkasa-teaching/nured_0109E_quantitative_methods). Τα πρωτότυπα αρχεία του μαθήματος χρησιμοποιούν `revealjs`, `custom.scss`, 1280×720, αριθμούς διαφανειών και υποσέλιδο.

## Προβολή και επεξεργασία

```bash
quarto render index.qmd --to revealjs
```

Η εντολή δημιουργεί `index.html`. Ανοίξτε το HTML στον φυλλομετρητή και πλοηγηθείτε με τα βέλη. Το Quarto πρέπει να είναι εγκατεστημένο (δεν απαιτείται R ή Python για την απόδοση, επειδή τα διαγράμματα περιλαμβάνονται ως SVG).

Για ένταξη στο αρχικό repository, αντιγράψτε ολόκληρο τον φάκελο (ως π.χ. `slides/lecture-anova/`) και προαιρετικά προσθέστε σύνδεσμο στη σελίδα `slides-index.qmd`. Δεν περιλαμβάνεται το πρωτότυπο πανεπιστημιακό λογότυπο· για να το χρησιμοποιήσετε, προσθέστε το δικό σας `logo.jpg` και `logo: logo.jpg` στις ρυθμίσεις `revealjs` του YAML.

## Περιεχόμενα

- `index.qmd`: πλήρης παρουσίαση revealjs με παράδειγμα τριών ομάδων, αναλυτικούς τύπους και ασκήσεις.
- `custom.scss`: στυλ εμπνευσμένο από την οπτική ταυτότητα των μαθημάτων.
- `figures/`: 10 διαγράμματα SVG με παιδικές επιδόσεις, μέσους όρους, αποκλίσεις SST/SSB/SSW και κατανομή F.
- `anova_data.csv`: δεδομένα 15 υποθετικών παιδιών σε μακρά μορφή, κατάλληλα για εισαγωγή στο jamovi.
- `scripts/generate_figures.py`: προαιρετικό script αναδημιουργίας των γραφημάτων (`pip install numpy matplotlib scipy`).

Ομάδα Α: `[2,3,4,5,6]`, Β: `[4,5,6,7,8]`, Γ: `[6,7,8,9,10]`.

- $SS_W=30$, $SS_B=40$, $SS_T=70$.
